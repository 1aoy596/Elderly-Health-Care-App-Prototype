# Elderly Health Care App

An Axure RP 9 mobile health assistant prototype for older adults.

Live demo: [Add GitHub Pages URL]

## Run locally

From this directory, run:

```sh
python -m http.server 8000
```

Open <http://localhost:8000/>. Serve over HTTP rather than opening the files directly so the Axure export can load its scripts and assets.

## Flows to try

- Start screen and login, then home
- Home screen bottom-bar tabs
- Medication voice-input steps 1-3
- SOS long press
- Back arrows
